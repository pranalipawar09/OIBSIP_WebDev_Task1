# Task 3 – Temperature Converter

This project is a Temperature Converter web application developed as part of the Oasis Infobyte Web Development & Designing Internship.

## Features
- Converts temperature between Celsius, Fahrenheit, and Kelvin
- Input validation for numeric values
- Clean and responsive UI
- Built using HTML, CSS, and JavaScript

## Technologies Used
- HTML
- CSS
- JavaScript

## Description
The user enters a temperature value, selects the input unit, and the application displays the converted values in other units instantly.

This project demonstrates basic JavaScript logic, DOM manipulation, and UI design skills.
